# 逐篇视觉判断

2026-10-28，依据用户要求：打破模板化，每次选题都发挥模型的审美判断。本补充覆盖旧规范中强制五幕剧、固定组件配额和固定视觉顺序的要求；真实性、审核授权和平台兼容性约束继续适用。

## 每篇从内容出发

选题研究时先判断材料的表达潜力；全文获准进入排版时，再根据实际正文和已审素材决定版式。用几句具体的话记录在本篇 review/visual_direction.md：读者最该看见什么，文字与图片如何推进阅读，哪些地方需要强调，为什么这些设计适合本篇。无需另设用户审批节点，不要求填写统一表格。

至少在内部比较几种可行表达，再实施最合适的一种。不是每篇必须换颜色、换字体，而是每个设计选择能回答具体的阅读需要。不得为了差异化堆装饰、拉长空白或牺牲可读性。

## 形式没有固定配额

- 不预设章节数、五幕顺序或“标题—文字—卡片—配图”的循环。五幕剧只作可选叙事参考。
- 不强制顶部摘要、数据卡、引语卡、金句或每节加粗。组件按表达需要选用；没有必要就省略。
- 视觉重点可以来自文字大小、留白、图像、对照关系或一句准确的重音，不等于必须有色块盒子。
- 中文读者默认不加英文栏目名、自封的“深度调查”标签、机械编号和文末品牌口号；确有编辑用途时再判断。
- 本次农村光伏稿的白底、克制配色、文字层级与留白，只是本篇已获认可的方向，不升级为所有文章的统一外观。

## 模板与素材的边界

模板提供受控渲染和可组合的排版能力，不注入具体行业数字、观点或段落顺序。逐篇样式应绑定本篇构建；确需调整共享模板，先检查其他文章的兼容性，不批量重建旧稿。

正文、数据、引语和图注仍来自源稿与可追溯证据。审美不得改变事实、虚构现场、冒充权威或重绑历史批准。

## 看过页面再判断

渲染后实际检查手机与桌面：首屏是否拥挤，连续几屏是否单调，图片是否切断论证，字号与对比是否舒适，强调是否过密。针对观察修正，不把技术检查通过或几个组件齐全当作“高级”的证明。无法实际查看时如实记录视觉验收未完成。

如果机器门禁仍硬性要求已撤销的组件配额，记录具体冲突并调整相应实现与测试，不靠塞空卡片过关，不关闭事实和交付检查。
