## 三、五幕剧硬核商业叙事结构（禁止教科书提纲与晚会升华）

正文严禁采用“从……说起”、“不神化……也不否定”、“理性看待……”等平庸说明文提纲，严禁文末出现“朝着更加健康与理性的方向稳步前行”、“推开了一扇更具价值的大门”等晚会主持词，统一遵循**五幕剧商业叙事张力**：

1. **第一幕（反常识痛点悬念入场）**：前150字直接抛出普通人在超市、餐厅、电费单或账单上感知到的剧烈价格反差、资本崩盘或法院传票起诉现场，配合顶部 `key_takeaways`（核心看点卡片）3秒锁死完读率。
   - 必须显式声明开篇变体（`opening_variant`）与叙事模式（`narrative_mode`）：
     - **V1（反常识价格与账单悬念）**
     - **V2（行业周期出清与破产崩盘现场）**
     - **V3（供应链咽喉卡死与数据打假）**
     - **V4（县域隐形冠军与全球平替突围）**
     - **V5（法律卷宗起诉与商业合同陷阱反差）**
2. **第二幕（脱下行业滤镜：概念与现实的撕裂）**：拆穿资本故事、高端营销或技术噱头背后的真实运转摩擦。
3. **第三幕（硬核拆账：1斤/1亩/1家店的成本底牌）**：调用 `items_box` 或 `comparison_card`，把毛利、损耗率、折旧、冷链或饲料账本用阿拉伯数字逐项摊开。
4. **第四幕（产业链生死博弈与洗牌格局）**：呈现跨国巨头、渠道商、加工厂或县域基地在成本红线下的真实博弈与出清。
5. **第五幕（冷峻收束与留白）**：以具体商业判断、竞争终局或留给读者的账单叩问利落收尾，绝不喊口号。

## 四、杂志级视觉排版八大铁律（A / D / F 全轨对齐）

`templates/track_a.html.j2`、`templates/track_d.html.j2`、`templates/track_f.html.j2` 已实现杂志组件全量对齐，并由 `scripts/editorial_policy.py` 强制门禁校验：

1. **冲突感短标题（8～18字）**：包含具体物种/商品/主体 + 反差动词或数字悬念；具体账本指标下沉至 `lead_hook` 与 `digest`。
2. **手机端呼吸感短段落（单段 ≤ 165字）**：每段严控在手机屏幕 2～4 行（约 60～135 字，硬上限 165 字），严禁超过 165 字的灰字文字墙。
3. **全文必配视觉锚点组件**：多章节成稿（≥4节）禁止“纯 `<p>` 裸奔”，全篇须配置顶部 `key_takeaways`（核心看点卡片）、至少 1 处 `items_box` / `comparison_card`（硬账拆解卡片）、至少 1 处 `quote_card` / `golden_quote` / `callout`，以及每节关键结论句的 `<strong>` 重点加粗。
4. **阿拉伯数字铁律**：统计指标、百分比、年份与金额一律使用高辨识度阿拉伯数字（如 `95%`、`0.1`、`2026年`），严禁在正文写“百分之九十五”、“零点一”、“二〇二六年”等汉字数字流水账。
5. **真图四零红线与先验查重**：每张入库 `photos/` 和封面的图片必经 `read_file` 肉眼审看（零AI/3D渲染、零商业水印广告、零清晰正面人脸、零图文错位），且历史与组内 dHash 汉明距离 > 30。
6. **字数安全水位（2550～2720字）与 UNIX LF 原子锁链**：含小标题与图注总汉字控在 2550～2720 字；所有 JSON/MD/TXT 强制 UNIX LF（`\n`）落盘，修改后运行 `python -X utf8 scripts/sync_hash_chain.py --dir <目录>` 一键级联自愈。
7. **国内题材真实配图优先与细节纯净化**：中国本土三农、光伏与司法题材一律优先选用中国本土公开权威纪实摄影（法院大楼、电网调度、真实连片村庄屋顶、本土车间）；严禁外文合同特写与西方面孔穿帮。
8. **图注单句场景说明与严禁句号**：图注严格限制为单句客观场景说明（10～22字），末尾严禁使用句号（`。`），不堆砌许可链接，保持杂志级极简视觉。
